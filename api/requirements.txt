# Dependencies for the deployed control plane ONLY.

# The root requirements.txt is the development and container set: it also
# carries numpy, scipy, pydub and elevenlabs. None of that is imported by

# sys.modules — so installing it here would add hundreds of megabytes to a
# function that never calls it, and pay for it on every cold start.
#
# If a route ever needs the engine, move that route to its own function
# rather than making this one heavy.

# Recording uploads (POST /calls/{id}/recording) are multipart forms, and
# FastAPI refuses to even define an upload route without this installed —
# the import of cynea.api fails, so every route would be down, not just one.

# Cloudflare R2 for call recordings, through its S3-compatible API. Only
# imported when the R2_* variables are set (cynea/recordings.py).

# The browser call demo (cynea/voice_ws.py). Each of these is an HTTP or
# WebSocket client rather than an audio library: transcription and the
# model are Groq over httpx, speech is Edge TTS over a socket to
# Microsoft, and the browser sends PCM the engine already understands.
# So the demo adds a socket, not a codec.
edge-tts==7.3.1    # 7.2.8 is refused by Microsoft with 403 (Sec-MS-GEC v2)
websockets==16.0
