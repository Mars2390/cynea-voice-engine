# Cynea Voice Engine - dependencies
#
# Pinned to exact versions. These were `>=` ranges, which meant an upstream
# release could break production without a single commit landing here, and
# two machines installing on different days got different stacks. Bump
# deliberately: change a pin, run the suite, commit the change.
#
# Verified working set: Python 3.11-3.13, captured 2026-08-25.

# --- API server -------------------------------------------------------

# --- speech-to-text ---------------------------------------------------
# openai-whisper is deliberately NOT pinned here. It pulls torch (~2 GB)
# and needs ffmpeg on PATH, which is a heavy default for anyone who only
# wants to run the tests. Two options:
#
#   local  : pip install openai-whisper==20250625   (also: apt install ffmpeg)
#   hosted : set GROQ_API_KEY and stt_provider="groq_whisper" - no install
#
# cynea_africa.transcriber.whisper.best_available_stt() picks whichever is
# present, so a deploy works either way. The Dockerfile installs the local
# one; see the ARG at the top of it to skip that and halve the image.
