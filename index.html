Spin up an agent, place a call, and stream the live transcript from your own backend.

# place an outbound call with an agent
from cynea import Engine
agent = Engine.load("kwame")
call  = agent.call("+233...")
for turn in call.stream():
    print(turn.speaker, turn.text)

Configure an agent

Persona, voice, language and escalation rules in one config.

{
  "name": "kwame",
  "voice": "en-GB-RyanNeural",
  "country": "GH",
  "persona": "hotel receptionist",
  "escalate_on": ["complaint", "refund"]
}

Handle an inbound call

Route a number to an agent and let the engine run the conversation.

from cynea import Engine
from cynea_africa import AfricasTalking

engine = Engine.load("kwame")
line   = AfricasTalking(number="+233...")
line.on_call(engine.handle)
line.serve()
